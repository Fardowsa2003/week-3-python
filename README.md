Grade Reporter & Bug Hunt
Files
grade_reporter.py — Assigns grades to five scores, counts passes and failures, and calculates the average score.
bug_hunt.py — Fixes three bugs in a while loop program that calculates the sum of numbers 1 through 5.
Bug Reflection

The hardest bug to find was the loop condition because the program could run without an error and still produce the wrong sum. I knew something was wrong when the result did not equal the expected answer of 15. Changing the condition to count <= 5 ensured that the loop included 5 in the total.
